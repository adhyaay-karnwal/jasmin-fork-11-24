01 · whytryjasmine.dev
What it is
A microVM for
every agent task.

Own kernel

Firecracker per sandbox. Hardware isolation, not namespaces.

Never booted

Restored from a memory snapshot of a booted template.

Internet, fenced

pip and git work. Metadata, host and other sandboxes don't.

Pause, fork

Pause between turns. Snapshot, then start copies.
