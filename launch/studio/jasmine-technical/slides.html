02 · buildtryjasmine.dev
2 · Copy nothing

Disk: XFS reflink

Cloning the template disk takes the same time for 50 MB as for 5 GB. Create and fork are O(1) in image size.

Memory: MAP_PRIVATE

Snapshot memory is mapped lazily. Pages load when the guest touches them, and clean pages are shared by every sandbox through the host page cache.

Result: resume cost doesn't depend on how much RAM the sandbox has, and N sandboxes don't cost N copies.

05 · snapshot safetytryjasmine.dev
5 · Networking without a single ip call
Every sandbox expects
the same tap0.
The snapshot has its network config baked in. So each sandbox gets its own namespace holding an identical tap, NATed out through a unique veth.
Namespaces are pre-built in a pool and recycled on delete. The create path never runs ip or iptables. Networking added nothing measurable.

How we measure
  • 01From the client. Wall-clock through the public API, never server-reported timings.
  • 02Same machine, or say so. fairbench runs all four systems on one host, interleaved and randomly ordered.
  • 03Don't tune to the test. Workload seeded at run time. A 40-op agent trace we never looked at while tuning.
  • 04Ties are ties. Medians with bootstrap 95% CIs. A win needs its interval clear of every other system's.
  • 05Publish the losses. On the homepage, next to the wins. Raw data in the repo.
