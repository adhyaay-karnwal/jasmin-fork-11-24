# Jasmine Cloud launch film: storylines

**Picked: A, "One line".** A stranger follows it: the error everyone without bare metal has hit, one variable fixing it, and a price they can compare.

## A. One line (picked)
Device: life before and after, then a number lands. Form: one terminal that rebuilds itself, then a container morph into a new world.
The real "no /dev/kvm" error fails twice on a big terminal. One `export JASMINE_URL=` line fixes it, and the URL becomes the name. A per-second cost meter runs beside a live REPL, through create, run, pause (the meter freezes) and run again. The meter then swells into a leaf-green field where the price lands: $0.030 an hour.
- First 2 s: a huge terminal with `sudo systemctl start jasmined` already typed; the error line prints in pink on the first beat.
- Beats: error → second error → one line → "Jasmine Cloud" → create / run / pause / run, with the meter → green price field and comparison → prepaid claim → end card.
- Look: brand dark #070807 for the terminal world, full leaf-green #a6e86b with black ink for the price world, Geist + JetBrains Mono, Bayer dither on transitions only.
- Sound: original synth score, D minor, 120 bpm. Half-time until the fix, the drop on the URL. A meter tick per second; the meter freezing cuts the hats.

## B. The receipt
Device: a number lands. Form: one frame that rebuilds.
An agent's day of work prints as a till receipt, line by line: 412 sandboxes, 9.6 vCPU-hours, paused hours at storage price. The total comes to cents, then the receipt folds into the mark.

## C. Thousand forks (bold)
Device: the object is the explanation. Form: an endless zoom.
One sandbox is snapshotted, and the camera dives into it as it splits into 2, 16, 256, then 1,000 cells across a host. It pulls back to show they all ran on credit worth less than a coffee.
