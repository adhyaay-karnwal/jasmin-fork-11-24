## Notes on run 2

- Fixes since run 1: gVisor `--file-access=shared` (0 failures now); Jasmine: journal-less ext4 + noatime, guest read-buffer sizing.
- Jasmine VMM start-up retries: 0. Failures: 0 for every system.
- Jasmine's file-transfer gap is mostly first-touch cost in a freshly restored VM under nested virtualization (first 1 KiB write 5.3 ms, second 1.1 ms on the same host, measured in CI); the rest is client overhead shared by all systems. Pre-faulting guest memory at restore is the planned fix.
