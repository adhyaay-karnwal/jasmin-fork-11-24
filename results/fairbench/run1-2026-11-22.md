## Notes on run 1

- gVisor's 11 agent-trace failures were a harness configuration error, not gVisor's: it ran with the default `--file-access=exclusive`, so files uploaded through Docker's archive API weren't visible inside. Fixed for run 2 (`--file-access=shared`).
- Warren's file-transfer times in this run include a regression introduced the same day (a 1 MiB guest read buffer for every read). Fixed for run 2.
- Warren VMM start-up retries in this run: 0.
